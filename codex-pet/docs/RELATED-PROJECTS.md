# Related Open-Source Projects

These projects solve a broader problem than Codex's fixed two-file pet renderer:

- [Clawd on Desk](https://github.com/rullerzhou-afk/clawd-on-desk) is a desktop pet focused on reacting to coding agents, including Codex. Its host application is the useful reference when agent-state integration matters.
- [OpenPets](https://github.com/alvinunreal/openpets) is a local-first desktop companion platform with a plugin SDK for schedules, storage, notifications, audio, commands, UI, and pet state.
- [oc-claw](https://github.com/rainnoon/oc-claw) is a smaller coding-agent-reactive desktop pet implemented with Tauri.

Do not assume Xiaoman's Codex atlas can be dropped into another host unchanged. Reuse the final art and adapt frame dimensions, state names, metadata, licensing, and behavior wiring to the target project's documented format.
